# Catalog refresh — 2026-10-03

This refresh reconciles the catalog with current public GitHub releases and
source heads. It does not build the refreshed source checkouts, install apps,
change Actions settings, or deploy the AltStore feed.

## Catalog changes

- The active catalog now has 32 repositories: 30 current `chrissotraidis`
  projects, DuskLight, and OpenGOAL. It contains 11 newly discovered projects
  and 20 refreshed source pins. Existing ignored checkouts were not synchronized.
- CTRPad's complete prior record is preserved in
  `catalog/unavailable-projects.json`; GitHub returned 404 for its repository
  and pinned source commit.
- Nine projects with no current public IPA asset remain in the catalog with
  their previous release records, but are excluded from the feed with
  `upstreamIPAWithdrawn`: AnnePad, BearBirdPad, BrawlerPad, F0X, HarkinianPad,
  MaskPad, PaperPad, SpaghettiPad, and StarshipPad. Their release endpoints
  returned 200 but had no IPA assets.
- Eleven new projects are tracked. AgePad is excluded pending review of its
  Steam-client integration and account-safety implications. KidPad is excluded
  pending review of its use of Kid Pix artwork and sounds. SunPad, KartPad, and
  MeleePad are excluded because the public IPAs are templates without playable
  game code; a user must run PadMint with their own game data and install the
  resulting private IPA. Other newly tracked projects have no audited public
  app IPA. Current PadMint recipe metadata is recorded in
  `catalog/padmint-releases.json`; personal outputs are not stored here.
- Current feed eligibility is limited to DuskLight and RAtouch. Actions remains
  disabled for cost, and the Pages feed was not deployed.

## Release evidence and changed policy facts

DuskLight v2.0.3 was added from its project-owned release. Its audited IPA has
77 archive entries, four Mach-O images (up from one in v1.4.1), and the new
`NSLocalNetworkUsageDescription`: “Dusklight allows network-enabled mods to
connect to devices on your local network.” The package contains these three
mods:

- `dev.twilitrealm.cosmetics.so`
- `dev.twilitrealm.luau.so`
- `dev.twilitrealm.randomizer.so`

The randomizer bundle includes eight `.bti` resources:
`fused_shadow_1.bti`, `fused_shadow_2.bti`, `fused_shadow_3.bti`,
`mirror_shard_1.bti`, `mirror_shard_2.bti`, `mirror_shard_3.bti`,
`mirror_shard_4.bti`, and `shadow_crystal.bti`. The release notes identify an
updated bundled Dusklight Randomizer but do not establish ownership of each
texture. The structural IPA audit rejects configured disc/ROM formats and
verifies packaging; it does not establish provenance or rights for every
embedded artwork resource. No broader “contains no copyrighted game data” claim
is made here.

SunPad v0.2.0 passes its package audit, with one Mach-O image instead of two in
v0.1.0-preview.4. Its release notes state that the public IPA contains no game
code or Nintendo keys. On an Apple Silicon Mac, PadMint translates the user's
own disc and adds private game code before installation; the installed app then
imports the same disc. The published IPA alone is therefore not a playable
AltStore app. It is tracked as a PadMint template and excluded from the feed.

KartPad v0.7.8 and MeleePad v0.2.1 public IPAs were downloaded once, checked
against the GitHub size and SHA-256, and passed the package auditor as arm64
iPhoneOS/iPad packages without recognized game-data files or signing material.
Their release notes explicitly identify them as non-playable shells: PadMint
adds a private game pack/module from the user's own disc, and users install the
PadMint result. The passing package audits do not make the public templates
playable, so both remain excluded. Audit receipts and downloaded templates are
kept under ignored `.build/refresh-20261003/releases/` for local review.

## Validation and limits

The imported DuskLight and RAtouch release assets are direct links to project
repositories with pinned tags, sizes, and hashes. The generated feed is checked
with the catalog validator and existing generator in cache-only mode. The DuskLight
v2.0.3 file reuses the already downloaded and audited receipt; DuskLight v1.4.1
and RAtouch v0.1.0 were downloaded once for this generation. GitHub release
metadata and source tags were checked remotely, and the cache-only generator
rechecks each feed IPA's size, SHA-256, and package structure. This is not a claim
that a normal online generator pass redownloaded every asset. These checks do not prove
physical-device acceptance, gameplay quality, rights to game trademarks or
embedded artwork, or user ownership of game data.

No existing recipe was rebuilt against its newly pinned source revision, and no
new project was built or installed. Local AltStore source generation does not
publish or deploy GitHub Pages. Workflow files remain in the repository, but
GitHub Actions is disabled.
